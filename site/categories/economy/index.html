Source and scope

GDP per capita uses World Bank World Development Indicators series NY.GDP.PCAP.CD. The published snapshot keeps the observation year, retrieval metadata, source attribution and license with the data. Current-US-dollar values are nominal and must not be interpreted as inflation-adjusted living-standard changes over time.

Expansion rule

GDP, growth, inflation and unemployment will only be added one slice at a time after the previous slice passes source, methodology, mobile, canonical, sitemap and regression gates. The current GDP-per-capita slice passed its source ingest and release gates before this hub was promoted.
