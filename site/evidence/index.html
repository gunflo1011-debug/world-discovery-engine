How to read this evidence

Revision ≠ growth

We compare two publications of the same reference-year estimate. The difference is a revision to published data, not population change between publication dates.

Zero is informative

If both vintages contain the same value, we report no revision rather than inventing a discovery.

Reproducible

Each route includes readable HTML plus JSON and CSV with exact archived source URLs.
