World Discovery publishes official global data with explicit observation years, source attribution and reproducible transformations. Human pages and machine-readable outputs are kept tied to the same verified records.

Current verified coverage: REAL population-revision evidence is published where archived releases pass comparability checks. CURRENT_VERIFIED Internet Use observations for IT.NET.USER.ZS and CURRENT_VERIFIED GDP per capita observations for NY.GDP.PCAP.CD are published as official same-year snapshots. Additional WDI indicators are exposed through the maintained data catalog with their own observation years and coverage.

How provenance is preserved

CheckPublication rule
Dataset identityThe official source family and indicator identity must be known.
Observation yearThe year attached to each value remains explicit; missing values are not silently replaced with another year.
GeographyCountry or territory identity is retained independently from the display label.
Units and semanticsNumerical differences are shown only when the compared values are compatible.
ProvenanceSource references and retained input metadata remain attached to the published data product.
TransformationDerived values must be reproducible from stored numerical inputs.
