Why the comparison is blocked

1 · SERIES FOUND

The code exists in both vintages

The archived files contain NY.GDP.MKTP.KD for the screened countries and 2023 reference year. This establishes presence, not safe comparability.

2 · WARNING

World Bank archive guidance warns that this GDP series code has historically represented different base years. Current metadata cannot prove the historical release-specific basis of each archive.
